> ✨ **プロジェクト概要**  
> 「Fold Craft Launcher」は、AndroidデバイスでMinecraft: Java Editionを快適にプレイするために開発されたランチャーです。全バージョンの実行やModの導入をサポートしています。

---

## 🚀 主な機能 (Features)

✅ **全バージョン対応**  
- Minecraft Java Edition の全バージョン（最新のスナップショットを含む）をサポート
- 主要なModローダーに対応：Forge / NeoForge / LiteLoader / OptiFine / Fabric / Quilt / Cleanroom...

⚙️ **ハイライト機能**  
- 多様なJava環境を内蔵（Java 8 / 17 / 21 / 25）およびカスタムJavaのインポートに対応
- 仮想マウス＆カスタマイズ可能なタッチ操作レイアウト
- FCLおよびZalithLauncher2の操作レイアウト互換（ZL2レイアウトの自動変換インポート）
- シェーダー（影MOD）のサポート（VirGL / Zink / MGレンダラー）
- 動的なリソース管理（Mod / Modパック / リソースパック / シェーダー / ワールドデータ）
- テーマのカスタマイズ（背景画像・カラーテーマ変更）
